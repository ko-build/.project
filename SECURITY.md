# Security Policy

## Reporting Security Issues

The ko maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/ko-build/ko/security/advisories/new) form.

For more details, see the [ko security policy](https://github.com/ko-build/ko/blob/main/SECURITY.md).
